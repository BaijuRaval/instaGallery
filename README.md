# instaGallery

A local-first Android folder browser for managing files directly in their folders.

## Current interface
- Opens directly into folder view; there are no separate **All** and **Folder** tabs.
- No built-in document, audio, or image viewer.
- Browse folders and subfolders, and use the existing file-management actions such as select, rename, move/copy, share, and delete where supported.
- Files are accessed locally on the device.

## Build
1. Open this repository in Android Studio (JDK 17).
2. Install Android SDK 35 and sync Gradle.
3. Run on an Android device/emulator (API 26+).
4. Grant the file access permission requested by Android.

## Project status
Build and test with Android Studio before distributing. Android storage permissions and access restrictions vary by Android version.

## Latest build
The debug APK is generated by the GitHub Actions workflow on every push to `main`.
